# Getting Started

Build and run MLXGenUI from its checked-in Xcode project.

## Requirements

Use an Apple Silicon Mac with macOS 15 or later and Xcode 26 or later. Install Homebrew separately from its official website. MLXGenUI then uses Homebrew to locate `uv`, and `uv` to locate MLX-Gen.

## Build the app

Open `MLXGenUI.xcodeproj`, choose the MLXGenUI scheme and My Mac destination, then run the app. A personal development team is sufficient for local builds.

Open **System Status** in the sidebar to inspect the backend installation. Open **Create Video** to choose a preset and edit a generation task.
